# 🏁 Invitación al cumpleaños de Gael — Hot Wheels Edition

Invitación interactiva con tema Hot Wheels: un auto entra haciendo curvas, frena y "lanza" la tarjeta de invitación al centro de la pantalla.

## Cómo correr

```bash
npm install
npm start
```

Abre `http://localhost:3000`.

## Estructura

- `src/components/Invitation.js` — escenario principal y tarjeta animada
- `src/components/Cars.js` — modelos SVG (Muscle, Sport, F1)
- `src/components/CarRace.js` — mini juego de carrera
- `src/components/Countdown.js` — cuenta regresiva
- `src/styles/` — CSS por componente
